忍者龙剑传 Σ1 功能补丁 0.6.22

「残影」页显示检测到的 CPU 和显卡。默认「自动」按游戏实际使用的显卡选择：独显用「常规优化」和完整轨迹，核显用「核显专项优化」，每帧最多绘制两层残影，遮罩宽高各减半。两种材质的发光和折射仍然生效。也可手动选择并点击「应用模式」，游戏运行中即可切换。设置按游戏目录保存。
诊断日志记录游戏实际使用的显卡、生效的模式，以及有残影和无残影时的帧提交间隔。

两种模式均使用当前的渲染兼容修正。核显专项优化会跳过自动场景深度采样。Intel 显卡在常规模式下也默认绕过可能导致闪退的深度清除钩子。墙面遮挡可能受影响。

安装器右上角可切换「简体中文 / English」。切换立即生效，安装器会记住上次选择。
窗口化时，只要游戏仍在运行战斗动作，鼠标移出或切换焦点后，震动和残影仍会随动作生效。

安装与还原
1. 正常退出游戏。解压后打开 NGS1RumblePatch.exe，选择游戏的 NINJA GAIDEN SIGMA.exe。
2. 在「震动与手柄」安装震动或 PS5 手柄支持，在「残影」安装残影。三个功能可各自安装、覆盖更新和还原。已安装 0.6.x 的用户可以直接更新。
3. 安装完成后，直接打开游戏 EXE 即可加载。安装器也提供「启动游戏」。兼容模式使用当前 Windows 用户的自动加载器，进游戏后需要几秒加载，关闭安装器后仍可使用。
4. 「全部还原」移除本补丁的自动加载项及运行目录。游戏 EXE、资源包、汉化文件和存档保留原样。

安装报错或游戏闪退
重新打开安装器，选中出问题的游戏 EXE，点击底部「导出诊断包」。核对 ZIP 内容后，可将它和复现步骤一起发给补丁作者。
诊断包包含最近的安装错误与 Windows 错误码、游戏版本及校验值、已有的自动加载／震动／残影日志，以及该游戏的 Windows 崩溃摘要。测试时如果 Windows 没有留下事件，摘要会标明。
如果能复现闪退，点击「追踪游戏闪退」，复现后再导出诊断包。如果残影不显示，做完相关动作后导出。残影日志会记录服装绘制和 GPU 合成覆盖率。
导出会遮盖游戏目录和 Windows 用户目录。ZIP 由玩家手动保存和发送。

残影设置
在「残影」中选择「原版材质」或「sigma2 材质」，再选服装。两种材质的发光强度以及 sigma2 的材质亮度均可调至 200%，各自的渲染贡献为 100% 的两倍。使用旧版运行库时，先点击「安装／更新残影」。
两种材质在可用时按场景深度处理遮挡，墙面等前景物体会挡住后方的残影。
点击「保存并应用材质」后，游戏运行中会自动重载。生效的材质会应用于所有服装，各套服装读取该材质下各自保存的参数。
默认黑衣、初期紫色忍者服、蓝色传说忍者服、Ashtar 盔甲和杀戮凶手均支持两种材质。动作规则沿用 0.5.9，残影来自当前服装的实际角色网格。
杀戮凶手右臂的红纹与左臂裸露皮肤使用同一种残影高亮颜色和亮度。手套和护具使用各自的材质亮度。
黑衣、蓝色传说忍者服和杀戮凶手提供「肌肉高亮程度」，默认 45%。100% 恢复之前的高亮力度，0% 关闭皮肤的额外高亮。其它两套服装隐藏这一项。
残影轮廓在转角处使用柔化覆盖率，沿用游戏的服装网格。
Ctrl+F11 可短时预览，Ctrl+F12 停止预览。旧版手动残影测试工具请在退出游戏后停用，避免重复接管渲染入口。

版本范围
已适配用户提供的 1.0.0.2 未汉化、1.0.0.4 @imjinjia 汉化，以及 1.0.0.4 未汉化样本。安装器检查核心代码和渲染入口指纹，同一文件版本号可能对应不同构建。
未知核心或不匹配的渲染入口会拒绝相应安装。若版本识别失败，请确认未安装其他会修改游戏程序的补丁，并检查是否选择了正确的 EXE。对其他渲染、模型替换插件的兼容性取决于它们修改的入口及资源。

手柄
支持震动、XInput 和 DualSense 热切换。DualSense 已验证 USB，蓝牙未实机验证。
安装 DualSense 功能后，内置图标会随当前手柄切换。用 DualSense 时显示 ×、○、□、△ 和 L1／R1、L2／R2，切回 Xbox 时恢复原图标。补丁在游戏运行时生成图标，无需另外下载。
