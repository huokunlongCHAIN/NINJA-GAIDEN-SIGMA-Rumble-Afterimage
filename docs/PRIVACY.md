# Privacy policy

This program will not transfer any information to other networked systems unless
specifically requested by the user or the person installing or operating it.

The mod processes controller input, game animation/render state, and vibration
output locally. The installer may read CPU/GPU information locally to select a
render profile. Settings, backups, installation results, and runtime diagnostic
logs are stored on the user's computer.

Export Diagnostics creates a local ZIP only when the user requests it. It can
contain game and mod versions, hardware and graphics information, installation
results, runtime logs, Windows crash summaries, and optional debugger stack/module
information. Known game and user directory prefixes are replaced with
placeholders, but exports may still contain identifying details. Review the ZIP
before sharing it. The program does not upload it automatically.

Trace Game Crash runs an optional visible Windows debugger helper after the user
requests it. No diagnostics are sent to the maintainer by this action.

GitHub, Nexus Mods, SignPath, and other websites have their own privacy policies
when visited independently; they are not telemetry destinations for this mod.
